## 搬瓦工换IP的三种情况，分别怎么处理

### 情况一：IP正常但想换一个

IP没被封，只是想换个地址，最省钱的办法是**切换机房**。

搬瓦工的VPS套餐大多支持在多个机房之间免费切换，每个机房分配的IP是独立的，切过去就拿到一个新的了。比如CN2 GIA-E套餐可以在12个以上机房之间随意迁移，DC6、DC9、日本软银、荷兰联通这些都能选，白嫖了好几个IP。

有个细节值得注意：如果你从机房A切到机房B，再切回机房A，大概率回到的还是原来那个IP，不会变。想真正换掉A机房的IP，中间要在B机房多待几天再迁回来，成功率会高一些。

### 情况二：IP被封，需要换一个干净的

这是最常见的情况，也是大多数人搜这个问题的原因。

IP被封的判断方法：登录KiwiVM控制面板，进入IP检测页面，点Test，出现"IP BLOCKED"就是被封了，出现"IP NOT BLOCKED"就没事。如果IP已经被封，切换机房的功能会被禁用，这时只有一条路：**付费更换IP**。

### 情况三：刚买不久发现IP就用不了

这种情况比较特殊。如果刚购买还没怎么用就发现IP有问题，可以先看看搬瓦工的退款政策，说不定退款重新下单比花钱换IP更划算。

## FAQ

**Q：搬瓦工续费之后IP会不会重置成新的？**

不会。续费只是延长服务时间，IP地址、数据、所有配置全部不变，续完接着用，什么都不用改。

**Q：搬瓦工IP被封之后能不能通过续费换到新IP？**

不能。续费和换IP是两件独立的事，IP被封只能通过付费换IP操作（$8.79/次），或者在IP未被封的状态下切换机房获取新IP。

**Q：切换机房一定会换IP吗？**

切换到新机房会得到新机房的IP。但如果从A切到B再切回A，大概率还是原来A机房的IP，不会变。要让A机房IP真正变化，中间需要在B机房多停几天。

**Q：搬瓦工过期了还能续费吗？**

到期后有7天缓冲期，这7天内付账单可以续上。超过7天账单失效就没办法续了，VPS也会被销毁。所以收到续费邮件尽量别拖太久。

**Q：换IP之后原来的数据还在吗？**

全在。换IP只改IP地址，服务器里所有文件、数据库、网站配置原封不动，不需要重新搭建任何东西。
